# 転生クオンツ / ISEKAI QUANT

> ここは人生演算装置〈回廊〉。あなたは転生者。死は終わりではない。

**遊ぶ**: https://kanta0410.github.io/something_new/ （スマホは「ホーム画面に追加」でアプリになる。オフラインでも動く。保存は端末内）

## これは何か

毎日 1 分開く、SF 仕立ての人生シミュレーター。3 つの層でできている。

1. **回廊（ゲーム）**: 世界 #seed で 22 歳から生きる。1 年は 1 タップ。市場は本物の反射的モデルで勝手にバブルと暴落を起こし、街には隠された相場と秘密がある。死ねば記憶結晶（スキル）を持って次の世界へ転生する。
2. **外界（現実）**: 現実で買い付けを出した、自転車で街を見た、本を読んだ、与えた、言語化した、失敗を自慢した——をタップすると、回廊の中のあなたが強くなる。連続日数が伸び、刻印（称号）が付く。これが「実社会での検証」の記録になる。
3. **残響（賢人）**: バフェット、ソロス、ヒンメルが毎年、状態を読んで語りかける。claude.ai 版では Claude が同じ人格で深く答える。

最初はシンプル。回廊レベルで機能が段階的に開く。

| 回廊 Lv | 開く条件 | 開くもの |
|---|---|---|
| 0 | 最初から | 外界同期、航路 2 択（守る／攻める）、1 年進める、残響 1 人、外界ログ |
| 1 | 転生 1 回 or 同期 7 日 | 学ぶ／遊ぶ、本棚、転生記録、同じ世界で転生 |
| 2 | 転生 2 回 or 同期 30 日 | 端末（街の地図で偵察・買い付けの提示額と LTV を自分で決める、クオンツ画面） |

「この世界」から先に全部開くこともできる。

## 何が入っているか

| モジュール | 中身 |
|---|---|
| `src/engine/market.js` | Brock–Hommes 型の反射的エージェントベース市場。ファンダメンタリストとチャーティストのシェアが成績で入れ替わり、内生的にバブルと暴落が起きる。バブルが大きいほど崩壊確率が上がる暴落ジャンプ（パニックのクラスタリング付き）。年次リターンは平均 5〜9%、標準偏差 16〜26%、負の歪度にキャリブレーション済み |
| `src/engine/city.js` | 6×6 の街。各地区に隠された真の相場・利回り・トレンド・秘密（再開発、新駅、浸水リスク…）。「偵察」で推定誤差が縮み、配達員や工事のおっちゃんの話として秘密が開示される。売主の本音 θ は混合分布（15% は投げ売り）なので、半額の買い付けでも時々通る |
| `src/engine/life.js` | 給与カーブ、累進税、生活費、Gompertz–Makeham 死亡ハザード（85歳生存率 ≈ 51%）、破産判定 |
| `src/engine/skills.js` | 5 スキル（読書・コミュ力・地域知・クオンツ・胆力）。`level = floor(sqrt(xp/40))`、転生で持ち越し |
| `src/engine/events.js` | アラモの時（暴落年）、達成者との出会い、ギブと返礼、病気、リストラ… |
| `src/engine/council.js` | 賢人会議。バフェット／ソロス／ヒンメルが状態を読んで毎年 1 言ずつ。Artifact 上では Claude が同じペルソナで実応答 |
| `src/engine/quant.js` | Kelly 基準（履歴から μ̂, σ̂ を推定、事前分布と混合）、モンテカルロ扇形図（市場モデルを本当に回す）、統計（CAGR, Sharpe, 最大ドローダウン） |
| `src/engine/score.js` | 人生スコア = 富 + 楽 + 学 + 縁 + 自慢。各 1000 点飽和 |
| `src/engine/game.js` | 1 年を進める統合、転生、保存 |
| `src/ui/` | 藍と朱のピクセル端末。Canvas 手描きチャート、街のグリッド、モーダル |

## 開発

```
npm install
npm run build      # dist/index.html（単一ファイル）
npm test           # 市場キャリブレーション、買い付け確率、死亡率、統合テスト
npm run sim 200    # 4 つの方針で 200 人生ずつ回してバランスを表にする
npm run shot       # Playwright でスクリーンショット
```

`dist/index.html` をブラウザで開くだけで動く。保存は localStorage。`main` に push すると GitHub Actions が `gh-pages` に配信し、GitHub Pages が更新される。

## 価値観 → ルール

| 価値観 | ルール |
|---|---|
| 死は終わりではない | 死亡・破産・自主転生でスキルを持ち越す。自主転生は胆力 +100 |
| アラモを忘れるな | 暴落年はエネルギー +40、売主の投げ売りが 3 倍。最悪の時が最高の時 |
| 失敗は自慢する | 却下された買い付け、損失、破産は自慢ポイント → 転生時 XP |
| 資産と負債を区別する | 物件はキャッシュフロー符号で「資産」「負債」。負債はバフェットが叱る |
| とにかく買い付けを出す | 売主の本音は混合分布。半額でも通ることがある。却下でも学び +2 |
| 現地を見る | 偵察で推定誤差が縮み、秘密が開示される |
| 無知に気づいたら自己教育 | クオンツ Lv で Kelly、扇形図、市場生態系が「見える」ようになる |

設計の全文は `docs/DESIGN.md`。

## AI プレイテスト（`npm run sim 60`）

4 つの固定方針で 60 人生ずつ回した結果。市場も街も同じ乱数系列。

| 方針 | 純資産@60 中央値 | p10 | p90 | 最終純資産 | 享年 | 破産率 | 物件数 | 買付通過率 |
|---|---|---|---|---|---|---|---|---|
| 放置（遊び 60%、株 0%） | 3,871万 | 1,883万 | 4,778万 | −784万 | 77 | 56.7% | 0 | – |
| 堅実（読書 30%、貯蓄 50%、株 60%） | 2.0億 | 1.5億 | 2.8億 | 4.1億 | 83 | 0% | 0 | – |
| 金持ち父さん（偵察 40%、毎年 3 本買い付け 70〜85%、LTV 80%） | 8.2億 | 3.6億 | 12.0億 | 27.7億 | 84 | 0% | 48 | 33.7% |
| ギャンブラー（株 100%、半額買い付け） | 2.8億 | 4,313万 | 7.0億 | 6.0億 | 79 | 0% | 0 | 2.4% |

毎日モードの 4 プリセットを一生続けた場合（60 人生ずつ）:

| 方針 | 純資産@60 中央値 | p10 | p90 | 享年 | スコア | 買付通過率 |
|---|---|---|---|---|---|---|
| 守る | 1.9億 | 1.2億 | 2.4億 | 81 | 2,745 | – |
| 攻める（安い売り物 3 本に 70%→50%） | 6.4億 | 2.0億 | 10.2億 | 81 | 4,125 | 16.4% |
| 学ぶ（本 2 冊/年） | 3.0億 | 1.9億 | 4.1億 | 82 | 3,143 | – |
| 遊ぶ | 1.1億 | 5,177万 | 1.4億 | 85 | 2,321 | – |

読み方：貯金だけの「放置」は定年後に半数近くが老後破産する。買い付けを出し続ける「金持ち父さん」は却下率 66% でも資産が 10 倍になる。行動すると事態が動く。

## 市場モデルのキャリブレーション（`npm test`）

12,000 年のシミュレーションで、年次トータルリターンの平均 7.8%、標準偏差 20.8%、歪度 −0.09、暴落年（−25% 未満）5.5%、20 年 CAGR が −2% を下回る確率 1.7%。バブル（本源価値比 +22% 超）は 3〜5% の年に出る。
